# homebrew-sigye

Homebrew tap for [sigye](https://github.com/am2rican5/sigye) — a beautiful terminal clock with ASCII art fonts.

## Install

```sh
brew install am2rican5/sigye/sigye
```

This installs a prebuilt binary (macOS arm64/x86_64, Linux arm64/x86_64); no Rust toolchain required.

> Use the full `am2rican5/sigye/sigye` path. On Homebrew 6.0+ a bare
> `brew install sigye` from a third-party tap is refused unless you first run
> `brew trust am2rican5/sigye`; the explicit path above needs no trust step.

The formula is updated automatically on each [sigye release](https://github.com/am2rican5/sigye/releases).
