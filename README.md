# homebrew-sigye

Homebrew tap for [sigye](https://github.com/am2rican5/sigye) — a beautiful terminal clock with ASCII art fonts.

## Install

```sh
brew install am2rican5/sigye
```

The formula installs a prebuilt binary (macOS arm64/x86_64, Linux arm64/x86_64); no Rust toolchain required.

The formula is updated automatically on each [sigye release](https://github.com/am2rican5/sigye/releases).
